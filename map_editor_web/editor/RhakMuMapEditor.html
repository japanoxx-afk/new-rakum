라크무 맵 에디터

라크무(RhakMu) .rkm 맵을 열고, 지형을 칠하고, 자원·장식물·시작 위치를 배치하고, 다시 저장합니다.

타일 그래픽은 에디터 옆 tiles 폴더에서 자동으로 불러옵니다.
라크무 폴더를 연결하면 Data\Maps 맵 목록에서 바로 열고 저장할 수 있습니다 (선택 사항).

맵 목록 (Data\Maps)

클릭하면 열립니다. 저장하면 이 폴더에 바로 저장되고, 덮어쓸 때는 .bak 백업이 남습니다.

선택 / 이동

오브젝트를 클릭해 선택, 드래그로 이동, Del로 삭제

언덕을 칠하면 절벽이, 물을 칠하면 물가가 자동으로 둘러집니다. 언덕 위에 높은 언덕을 칠하면 2단 고지대가 됩니다.
크기를 맨 왼쪽 벽으로 하면 언덕·높은 언덕·고지대 물이 꼭대기 없이 가장 얇은 절벽 경계만 그려집니다. ╱ 직선과 함께 쓰면 지나갈 수 없는 벽이 됩니다.
언덕길 · 다리 · 폭포
2층 언덕 입구는 평지↔언덕(1단), 3층은 언덕(1단)↔높은 언덕(2단) 사이 절벽에 놓습니다. 다리는 물 위, 폭포는 고지대 물 가장자리에 놓습니다.
(상하대칭) 입구는 언덕의 윗쪽 절벽용이며, 게임 폴더에 상하대칭 모드(Data\tile)가 설치되어 있어야 게임에서 보입니다.
