## 1) 첫 어긋남 8525프레임 (4분 44초) — 원인 확정: 재생의 지도 공개
- 재생 start 루틴이 [0xB412C8] |= 1 (지도 공개 치트) + 0x4991E0 를 부른다.
- 0x49b6a0 (60프레임마다 시뮬레이션 루프 0x4d586d 에서 부름): 비트 1이 켜져 있으면 모든 유닛의 시야 마스크
  (유닛+0x5C)를 0xFF 로 채운다 -> 모든 플레이어가 모든 유닛을 "본다".
- 자동 공격(대상 잡기)이 이 마스크를 써서, 플레이어 0의 무사 33·41 이 원래보다 일찍 적 버서커 56 을 보고 움직였다.
  디버거(해시 루틴 실행 중단점)로 8515/8520/8525 유닛 표를 덤프: 8515·8520 해시 일치, 8525 는
  무사 33(x+3)·41(x+6)이 안 움직였다고 보면 기록 해시와 정확히 일치.
- 지도 공개를 빼고 재생하면 8525 어긋남이 사라진다.
- 유닛 그리기 판정: 0x4690fe (유닛+0x5C & 로컬 플레이어 비트). 화면만 공개하려면 그리기 쪽 처리가 따로 필요.
