# 같은 건물 여러 개로 생산·업그레이드 나눠 맡기기 (v0.9086, `production_split_patch.py`)

## 분석 (Rhakmu.exe 1.000d)
- 생산·연구 버튼(0x45F92B..)은 명령 0x4008 `[0x4008][9][유닛 word][세부 byte][값 word]` 를
  0x447CF0(종류, 유닛, 세부, 값) 으로 보낸다. 유닛 = 정보 창 유닛 [0xB412D0].
- 실행 0x4416A0, 세부 표 0x4422CF (세부 5..10):
  - 5 생산 0x1005 (0x44185E): 체력>0, 예약 +0x52 < 4, 쉬면 시작(0x439750) / 0x1005 중이면 예약(+0x54 목록) / 다른 일이면 무시.
  - 6 연구 0x1006 (0x4416D3), 10 0x100A (0x4417D5): 쉬고 있을 때만 (명령 & 0x1000 이면 무시).
  - 7·8·9 변신류 0x1007..0x1009 (그대로 둠).
- 더블클릭 0x4314C7 -> 같은 종류 선택 0x4335F0: 0x43360E 누른 유닛이 건물이면 그만, 0x433AD8 화면 탐색에서 건물 건너뜀.
  건물은 점유 표 0xB839CA 에 모양대로 들어 있어(0x4366E0) 탐색에 잡힌다. 중복은 0xB412E4 의 0x80 표시로 막힌다.
- 선택 확정 0x432F30: 모두 같은 종류면 첫 유닛을 [0xB412D0] 으로 -> 패널 0x4603D0 이 건물 버튼(0x45FBA0)을 그림.
  정보 창 건물이 바쁘면(0x1005 제외) 0x4604BB 에서 '취소' 패널(0x460630)만.
- 이동 명령 0x441240 은 첫 선택이 건물이면 아무것도 안 함 (건물만 고른 상태에서 우클릭해도 안전).

## 패치
1. 0x433603 (18B): '건물이면 그만' -> '내 유닛이 아니면 그만'.
2. 0x433AD8 jne -> nop: 탐색에서 건물도 (같은 종류·내 것 검사는 원래 코드).
3. 0x447CF0 머리 -> 여유 공간 5조각 (entry 0x4EBCC0, pick 0x4EB9C8, scan 0x4EB950, load 0x4EB7D0, load2 0x4EB8D0):
   0x4008 세부 5/6/10 이면 선택 목록(주소는 0x43366E 의 값 — 선택 한도 24 패치가 옮김) 중 같은 종류·내 것·체력>0 건물의
   할 일 수(쉼 0, 생산 중 1+예약, 그 밖 불가)가 가장 적은 건물로 바꿈. 같으면 정보 창 건물, 그다음 선택 순서.
4. 0x46049F (30B): 선택 2개 이상이면 정보 창 건물이 바빠도 버튼 패널.
5. 0x447E60 머리 (집결지 등 건물 명령 0x400E 보내기, 우클릭 0x43194F·미니맵 0x467DA6/0x4702D6) -> 부명령 3(집결지)이고
   선택이 2개 이상이면 선택 중 같은 종류·내 것·체력>0 건물마다 [0xB412D0] 을 잠깐 그 건물로 두고 원래 함수를 불러
   0x400E 를 하나씩 보낸다 (건설 중 집결지 패치의 보내는 쪽 검사도 건물마다 그대로). 끝나면 [0xB412D0] 을 되돌림.
코드 조각은 남은 .text 여유 공간(잘게 나뉨) 11곳에 나눠 jmp 로 잇는다 (CHUNKS, assemble() 이 이름을 조각 사이에서 풂).

보내는 쪽만 바뀌므로 대전 동기화와 무관 (상대가 이전 버전이어도 됨).

## 남은 것 / 다른 점
- 대기열 아이콘·진행 표시는 정보 창 건물 기준.
- ESC(대기열 취소)는 선택한 건물마다 하나씩 취소된다 (queue_cancel_patch, 선택한 유닛마다 보냄).
- 드래그 선택은 원래처럼 유닛만 (건물은 더블클릭).
