# 집결지: 건설 중 지정 + 집결지 쪽 생산 위치 (Rhakmu.exe 1.000d)

브랜치 `launcher-v0.9074-rally-spawn` (worktree `%USERPROFILE%\Documents\claud\rhakmu-rally`, origin/main 9f4f6ff 기준).
v0.9073 은 origin 의 `launcher-v0.9073-replay-continue` 가 이미 씀.

## 집결지 명령 경로
- 우클릭 0x431800 → (고른 건물이 내 것, 건물표 0x4FE474+종류*0x14 의 +0x3E&2) → 0x447E60(부명령 3, 대상, 층 [0xB412CD], 지점 [0x6E68BC] 픽셀)
- 0x447E60 이 명령 0x400E 패킷: [0x400E][0x0F][부명령 w][건물 w][대상 w][층 b][지점 dword]
  - 보내기 전 고른 건물 상태(+6)&0x1000 이면 (상태&0xFFF)-4 로 표 0x447F52 → 0 이면 안 보냄(0x447EC4).
    막는 상태: 0x1004(건설 중), 0x1007, 0x1008, 0x100D. **이것이 유일한 차단점.**
- 실행부 0x4407E0 → 0x443700(부명령 3): 상태 검사 없이 건물 +0x5E = 층(0xFF 없음), +0x60 = 지점. 대상==건물이면 0xFF(해제).
- +0x5E 는 건물 놓을 때(0x43D270, 0x43CD50) 0xFF 로 초기화, 건설 완료 때 안 지움.
- 다른 부명령: 1 → +0x1C 공격 대상, 2 → 해제, 0x11 → 상태 0x2011 (건설 중에 허용하면 위험해서 안 풀었음).

## .text 여유 공간 (모든 빌드 조합에서 확인)
0x4EBAB0(0x50) 0x4EBB80(0x80) 0x4EBDA0(0x60) 0x4EBE10(0x30) 0x4EBF50(0x30) — 이번 패치가 모두 씀.
각 구간 끝까지 NOP/0 으로 채워 이 패치 소유(state 검사)라 .text 에 0x20 이상 빈 곳은 더 없음. 다음 패치는 섹션 추가가 필요.
viewport_patch 는 정규화 파일 전체 SHA256 을 보므로 .text 패치는 minimap_patch._strip_text_patches 에 넣어야 함.
